This project analyzes the growth in the number of Netflix Movies/TV Shows from 4 different regions from 2016 - 2021, to see which region has had the highest catalogue growth during this time. The 4 regions analyzed are APAC (Asia-Pacific), EMEA (Europe, Middle East and Africa), LATAM (Latin America) and UCAN (U.S. and Canada)

The source data, netflix_titles.csv, was obtained from this Kaggle dataset made by Shivam Bansal: https://www.kaggle.com/datasets/shivamb/netflix-shows
